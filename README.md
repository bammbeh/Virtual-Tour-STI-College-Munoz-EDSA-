# Virtual Campus Tour for STI College Muñoz EDSA

Welcome to the **Virtual Campus Tour for STI College Muñoz EDSA**! This project is designed to give prospective students, parents, and visitors an immersive and interactive experience of the campus, all from the comfort of their homes.

Explore the campus online, learn about the various facilities, and get a sense of what it’s like to study at STI College Muñoz EDSA.

---

## 🚀 Project Overview

The **Virtual Campus Tour** is an interactive web-based application that allows users to explore different areas of the campus. The tour features 360° images of key areas and offers detailed information about the campus facilities, programs, and environment.

---

## 🏆 Key Features

- **360° Interactive Tour**: Navigate through panoramic images of important campus areas such as classrooms, the cafeteria, and outdoor spaces.
- **Detailed Descriptions**: Learn about each area in the campus, with informative text and details on facilities and programs.
- **Mobile-Responsive**: The tour is designed to be fully functional on both desktop and mobile devices.
- **User-Friendly Navigation**: Easy-to-use interface for seamless interaction with the tour.

---

## 💻 Technologies Used

This project uses a combination of technologies to deliver a smooth and interactive experience:

- **HTML5** & **CSS3** – Used for structuring and styling the tour pages.
- **JavaScript** – For interactive elements, including navigation and image display.
- **360° Image Viewer** – To display interactive panoramic images of the campus.
- **Live Server (VS Code)** – Used for local development and testing during project creation.

## 🚀 How to Use the Virtual Campus Tour

1. **Open the Tour**:  
   Launch the `index.html` file in your browser to start the tour. You will be presented with the main campus areas to explore.

2. **Navigate Through the Campus**:  
   Use your mouse or touch gestures to explore the 360° images. Click on interactive elements to learn more about specific areas or facilities.

3. **Learn More**:  
   As you navigate, you’ll see descriptive text providing more information about the areas you’re exploring.
